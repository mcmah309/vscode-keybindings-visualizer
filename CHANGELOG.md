# Changelog

## 0.1.0

- Add an interactive US QWERTY keyboard with modifier layers, custom-binding accents, candidate details, and chord navigation.
- Combine VS Code's generated defaults with JSONC custom rules, including removal and disabling rules.
- Add command and shortcut search, a Custom only filter, profile discovery, file selection, and a configurable keybindings file.
- Watch custom files and preview unsaved edits, preserving UI state and retaining last-valid bindings on errors.
- Add themed accessible controls, development tooling, automated checks, and local VSIX packaging.
